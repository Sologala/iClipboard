# AGENTS.md

Tray app that shares the Linux system clipboard over LAN HTTP so an iOS Shortcut can
copy/paste without extra iOS software. All code is `package main` in the repo root:
no subpackages, no test files.

## Build / verify
- Requires Go 1.26+ (the `go` directive was raised by the 2026 dependency bump; older
  toolchains cannot build it).
- Building requires CGO plus GTK appindicator dev libs (`github.com/getlantern/systray`).
  A plain `go build` fails without them. Debian/Ubuntu:
  `sudo apt-get install gcc libgtk-3-dev libayatana-appindicator3-dev` (CI does this).
- `./build.sh` → `go build -o output/uniclip`. The binary is `output/uniclip`
  (gitignored), not `iClipboard`.
- `go vet ./...` and `go test ./...` — there are no test files; CI still runs
  `go test -v ./...` as a gate.
- `go mod tidy` runs in CI and in the goreleaser pre-hook. goreleaser publishes a
  release on **every** push and pull request (`.github/workflows/build.yml`).
- `renovate.json` drives dependency updates; it sets `gomodTidy` so module bumps keep
  `go.sum` in sync.

## Layout / entrypoints
- `main.go` — systray setup and menu. The "Enabled" checkbox flips `ServiceFlag`.
- `server.go` — gin server and all request handling (routing, auth, clipboard read/write).
- `config.go` — YAML config creation/loading. `config.yaml` is read from the CWD and
  auto-created with defaults if missing.
- `icon.go` — generated by 2goarray; do not hand-edit (its `//+build linux darwin` tag
  is the old build-tag style).

## Server contract (not documented in README)
- `GET /` returns the current clipboard; `POST /` sets it; everything else → 404.
- Required headers: `X-API-Version: 1` (hard-coded `apiVersion`); `X-Content-Type:
  text|file` on POST; optional `X-Auth` = md5(`authkey + "." + floor(unixtime/authkey_expired_timeout)`).
- Text body: `{"data": "..."}`. File body: `{"data":[{"name":"*.png","base64":"..."}]}` —
  only `.png`-named files are accepted.
- When the tray toggle is off (`ServiceFlag == false`), both handlers return 400.

## Gotchas
- `Config.LoadConfig` has a **value receiver**, so `yaml.Unmarshal` writes to a copy:
  `config.yaml` values are never applied at runtime — defaults (port `8086`, empty
  `authkey`) always win. Fixing this needs a pointer receiver.
- Logging is zerolog at `ErrorLevel`, and `main` calls `InitLogger(true)` (stdio), so
  INFO-level logs are suppressed.
- Comments and log strings mix English and Chinese.
- At startup `systray` prints `libayatana-appindicator is deprecated`. It is a harmless
  warning from `systray` v1.2.2 (its latest release calls the deprecated C API), not a bug
  in this code; ignore it.
